# Automation scripts

The inventory of everything under `scripts/`, every npm entry point, and every
scheduled GitHub Action in this repo.

The tables below are generated from the repo, so they cannot drift the way the
hand-kept version did. Regenerate them after adding or renaming a script.

```bash
npm run docs:automation           # rewrite the tables
npm run docs:automation -- --check # fail if they are stale or a script has no description
```

The Purpose column comes from each file's own leading comment. When a file has
no header comment, an entry in the `DESCRIPTIONS` map at the
top of `scripts/generateAutomationInventory.mjs` supplies it, and that map also
overrides a header that opens with a setup note instead of a description. A
script with neither shows as
undocumented and fails `--check`, so the fix is to write a one-line header
comment in the script itself.

## Notes

`netlify/functions/purge-cache.ts` is not a snapshot refresh pipeline. It purges
the Netlify Durable Cache and is protected by `CRON_SECRET`, so it does not
appear in the workflow table.

The fantasy draft companion side panel is built with `npm run build:fantasy-companion`
and loaded unpacked from `extension/dist`. Nothing schedules that build, since the
panel fetches the published snapshot at open and only falls back to its packaged
copy when both the network and its saved copy are unavailable.
