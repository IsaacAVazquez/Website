# Site improvements on October 9, 2026

Application search now includes posting facts, application channels, and fit notes. The pipeline has an agenda for scheduled interviews from today through six days ahead, with an edit button and a button that copies the preparation file's local path. Status changes are preserved through imports and merges, and the history display reports recorded stage durations. Conversion rates include earlier stages and archived records when the application contains evidence of that progress. Imported observations are labeled separately because their transition dates are unknown.

Before You Buy leads Home's selected work and has a finished illustration, a build article, and build-note links. The [plate record](PROJECT_PLATES.md) contains the asset path, original-generation mode, and final prompt. Site search reads published article bodies and includes every registered dashboard route through its case study, and the search route's test fails if a registered route is missing. Repeated body matches have a capped score, and article bodies stay out of API responses.

Print styles use fixed Catalog 97 tokens from a 740px layout. Responsive utilities widen only on screen, route width queries name their media, and the writing archive and résumé capabilities use block flow. The footer's contents use block flow inside the two-column group, which is kept together. Home's project and collage illustrations and the portfolio images load eagerly. The 404 tear uses a clip path, and decorative masks come off paper. The implementation reference for responsive utility rules is [Tailwind's custom variant directive](https://tailwindcss.com/docs/functions-and-directives#custom-variant).

The full unit run covered 438 suites and 4,118 tests. It passed 4,112 tests inside the sandbox, and the six tests that needed socket or subprocess access passed when those two suites ran outside it. The changed areas also passed a final targeted run of 146 tests. Lint, TypeScript, and the Node 22 production build passed. Browser checks passed 32 homepage, writing, search, résumé, and Before You Buy tests, plus 47 print tests across Chromium, Firefox, and WebKit, with seven browser-specific checks skipped as expected. Removing the search repetition cap caused its ranking test to fail, and restoring the cap passed.

An isolated browser check confirmed posting-fact search, preserved history after rejection, identical print token values at 740px and 1600px, block footer contents, six loaded illustrations before scrolling, and no visible masks on Home under print media.
